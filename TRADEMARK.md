# Name and Logo Policy

This policy explains how the name "Venturine" and the Venturine logo may be used. It is not legal advice.

## Status

This project makes no claim that "Venturine" is a registered trademark, and it does not claim that exclusive rights in the name or logo have been established. This policy states the project's intent about branding. It does not assert any registration.

**The Apache License does not grant permission to use the Venturine name or logo as branding for independent products or services.** Section 6 of the license says it does not grant permission to use the licensor's names, trademarks, service marks or product names, except for reasonable and customary use in describing the origin of the work and reproducing the content of the NOTICE file. This policy applies that principle to Venturine.

## Permitted uses

You may, without asking:

- Refer to Venturine accurately to describe this project, for example "based on Venturine", "compatible with Venturine" or "a fork of Venturine".
- Link to this repository and describe what it does.
- Keep the name and attribution in unmodified copies, and in the copyright, license and NOTICE text the Apache License requires.
- Use the name in articles, reviews, tutorials and discussion about the project.

## Uses that need a different name

If you distribute a modified version or an independent product, please:

- Choose a different name and logo for it.
- Do not present it as the official Venturine project, or imply the project's author or contributors endorse it.
- Do not use the Venturine logo as the logo or app icon of your product.
- State clearly that it is a modification or fork, mark changed files, and keep the license and NOTICE attributions.

## Questions

To ask about a use that is not covered here, open a GitHub issue. Please do not assume permission for a use this policy does not mention.

This policy may change as the project grows. Changes will appear in the repository history.
