# Venturine v0.2.1

Foundations and adoption hygiene, plus two calculator fixes from a pre-release audit. This release prepares the project for a public beta without changing analysis behavior.

## Highlights

- **Licensing and naming.** Apache License 2.0 (`LICENSE` and `NOTICE`) and a name and logo policy (`TRADEMARK.md`) that makes no registration claim. The license does not grant permission to use the Venturine name or logo as branding for independent products.
- **Documentation.** A rewritten README with a quick start, plus guides for examples, security and privacy, the competitive landscape and the roadmap.
- **Community files.** Contributing guide, code of conduct, security policy, issue forms and a pull request template.
- **Safer CI.** Actions pinned to commit SHAs, the Claude Code CLI pinned to an exact version, job timeouts, and no persisted checkout credentials.
- **Repository tests.** New tests check agent permissions (no `Bash`), manifest and changelog consistency, relative links, workflow pinning, required files and the social preview image.
- **Assets.** Logo and a 1280×640 social preview image.

## Calculator fixes

- **Run by file path.** The documented command is now `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/calculate.py" ...`. The old `python3 -m scripts.calculate` form could run an unrelated project's `scripts` folder if one existed in your working directory.
- **Bounded and clean failures.** Nonzero inputs below 0.000000001 are now rejected, absurdly large break-even results are rejected, and every error is a clean message instead of a traceback. One extreme input previously consumed about 28 seconds of CPU.
- Engine version is 0.2.1.

## Compatibility

One behavior change: inputs that are nonzero but smaller than 0.000000001 in absolute value are now rejected. If you set a Claude Code permission rule for the old `python3 -m scripts.calculate` command, replace it with the path form. All calculator commands and skills otherwise behave as in 0.2.0. The two web-enabled agents, `research-lead` and `evidence-auditor`, gained an "Untrusted Content" section and a rule against confidential details in search queries. Their tool permissions are unchanged.

## Upgrade

Update the plugin through Claude Code's plugin manager. No configuration is needed.

## Known limitations

- The `operating-profit` margin field is printed with many decimal places. Round it when reporting.
- The five-minute quick start has not yet been timed with outside testers.
- The repository is private during the beta, so installation requires access.
