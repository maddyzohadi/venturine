# Venturine v0.3.0

From 4 skills and 3 agents to 12 skills and 6 agents: a shared handoff format, independent review, forecasting and pricing, customer and growth analysis, and an integrated business report. This is a beta. Venturine is AI-assisted analysis, not a source of verified facts, so check anything that matters.

## Highlights

- **Evidence you can carry between steps.** The [`venturine-handoff/v1`](../handoff-v1.md) format moves an analysis between skills with every evidence label, calculation input and review intact. A standard-library validator checks it. Output is unchanged unless you ask for a handoff.
- **Intake and review.** `venture-intake` structures a rough idea. `evidence-audit` and the `evidence-auditor` agent give a second AI review pass, and `red-team-reviewer` argues the strongest case against a conclusion. These are AI passes, not human audits.
- **Forecasting and pricing.** `scenario-comparison` and `pricing-analysis`, backed by a deterministic forecasting calculator (`scripts/forecast.py`) whose results carry a reproducible receipt.
- **Customer and growth.** `customer-discovery`, `go-to-market` and `assumption-ledger`, plus the `go-to-market-strategist` agent. Channel economics come from the calculator, and interview findings never make a claim `VERIFIED`.
- **Integrated report.** `business-report` combines the findings into one report, keeping every label, receipt and contradiction. The `report-editor` agent checks it against its source findings. It has no web or shell access and its clean verdict is not an audit.
- **Citation accuracy.** `business-report` now cites each figure to the calculation that produced it, and `report-editor` checks every reference claim by claim. A native test had found a figure cited to the wrong calculation.

## Compatibility

- The calculator engine stays at 0.2.1 with its nine operations, and existing skills and agents keep their default behavior. The `venturine-handoff/v1` additions are compatible, so earlier handoffs stay valid.
- Python 3.9 or newer is required, and the standard library is all that is used.
- `research-lead`, `evidence-auditor`, `red-team-reviewer` and `go-to-market-strategist` can search and fetch public web pages. `report-editor` and `financial-analyst` cannot. No agent has shell access.

## Upgrade

Update the plugin through Claude Code's plugin manager. No configuration is needed. To install it fresh, run `/plugin marketplace add maddyzohadi/venturine` and then `/plugin install venturine@venturine-marketplace`.

## Known limitations

- Repeat-purchase customer lifetime value is not built. Forecasts assume what you give them, and the price comparison does not model how demand responds to price.
- Skill and agent behavior depends on an AI model following written instructions. Tests cover the deterministic parts (calculators, validator, structure) and wording, and a small number of native runs checked the rest, so wrong or missing findings are still possible.
- The five-minute quick start has not been timed with outside testers.
